# JSX — Conference Event Planner

Ứng dụng **React** tính chi phí đặt hội nghị: chọn địa điểm, số người tham dự và
các dịch vụ đi kèm.

## Thành phần

- `src/App.jsx` — state chính, chuyển giữa trang giới thiệu và form đặt chỗ.
- `src/ConferenceEvent.jsx` — form chọn địa điểm/số lượng.
- `src/TotalCost.jsx` — tính và hiển thị tổng chi phí.
- `src/AboutUs.jsx` — trang giới thiệu.
- `public/` — ảnh minh hoạ địa điểm.

## Chạy

```bash
npm install
npm run dev
```

Build: `npm run build`.
